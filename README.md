# Study-mkre — Preparação Mackenzie

Repositório de estudos para o Processo Seletivo da Universidade Presbiteriana Mackenzie.

## Conteúdo

- [`analise-prova-2026-1-grupo1.md`](analise-prova-2026-1-grupo1.md) — análise questão a questão da prova
  de 26/11/2025 (Grupo 1 — 1º semestre de 2026), com mapa de conteúdos e prioridades de estudo.

## Como usar

O arquivo de análise está organizado em três camadas:

1. **Mapa de pesos** — quantas questões cada matéria vale e o que isso significa na prática.
2. **Prioridade alta** — Português, Matemática e Geografia detalhados tópico a tópico.
3. **Demais matérias** — Física, Química, Biologia, História e Inglês em formato de checklist.

Cada tópico está marcado com a questão de origem, para você voltar à prova e conferir o enunciado real.
